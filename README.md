# Tarot Ontology

An RDF ontology for tarot, plus supporting vocabularies and datasets describing the Rider-Waite-Smith, Marseille and Sola Busca decks.

## Documentation

Full documentation (the ontology, vocabularies, example decks and design philosophy) is at <https://mikeyhogarth.github.io/tarot-ontology/>. See [DEVELOPING.md](DEVELOPING.md) for setup, tests and building the site.
